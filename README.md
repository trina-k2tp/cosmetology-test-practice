## 🌟 CÁC TÍNH NĂNG CHÍNH

1. **2 Bộ Đề Thi Độc Lập:**
   - **Bộ đề 424 câu chính thức:** Phân bổ đầy đủ 10 Session, thi thử ngẫu nhiên 110 câu.
   - **Bộ đề 100 câu mới nhất:** Bộ đề độc lập 100 câu cập nhật mới.
2. **4 Chế Độ Học Tập Toàn Diện:**
   - 🎯 **Thi thử tính giờ:** 120 phút, chấm điểm tức thì, thống kê đậu/rớt và điểm theo từng Session.
   - 📝 **Luyện tập theo chủ đề:** Chọn câu hỏi theo Session, xem ngay đáp án đúng/sai.
   - 🗂️ **Học thẻ ghi nhớ (Flashcards):** Tự động lọc các câu chưa thuộc, đánh dấu đã ghi nhớ.
   - 📑 **Tóm tắt lý thuyết 10 Session:** Trình bày phân cấp rõ ràng (A, B, C và tiểu mục), tự động in đậm từ khóa, tra cứu nhanh với highlight.
3. **Đồng Bộ Tiến Độ Đa Thiết Bị (Máy Tính ↔ Điện Thoại):**
   - Học trên máy tính xong có thể chuyển sang điện thoại (iPhone/Android) tiếp tục học ngay lập tức mà không mất dữ liệu.
   - Hỗ trợ lưu đám mây tự động (Cloud Auto-Sync) và chuyển tiến độ 1-chạm bằng đường dẫn.

## 🚀 HƯỚNG DẪN BẬT GITHUB PAGES ĐỂ HỌC TRÊN ĐIỆN THOẠI

1. Sau khi đẩy toàn bộ mã nguồn lên repository GitHub của bạn:
2. Nhấp vào tab **Settings** của repository trên GitHub.
3. Ở cột bên trái, chọn mục **Pages** (dưới nhóm *Code and automation*).
4. Tại phần **Build and deployment** -> **Branch**:
   - Chọn nhánh **`main`**
   - Chọn thư mục **`/(root)`**
   - Nhấn nút **Save**.
5. Đợi khoảng 1-2 phút, GitHub sẽ cung cấp cho bạn một đường link trang web dạng:
   👉 `https://<tên-tài-khoản-github>.github.io/<tên-repo>/`
6. Mở link này trên trình duyệt **Safari** (iPhone) hoặc **Chrome** (Android):
   - **Trên iPhone:** Bấm nút *Chia sẻ (Share)* ở thanh dưới cùng Safari -> Chọn **"Thêm vào Màn hình chính" (Add to Home Screen)**.
   - Ứng dụng sẽ xuất hiện như một app độc lập trên điện thoại để bạn mở ra học mọi lúc mọi nơi!
